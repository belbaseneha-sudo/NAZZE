# NAZZÉ — Fashion Shopping App

NAZZÉ is a mobile fashion shopping application created as a university project. I designed the app in Figma and worked on its Flutter front-end implementation.

## Features
- Product browsing and filtering
- Product search and wishlist
- Shopping bag
- Simulated checkout

## Design and Testing
I created the interface and user flows in Figma. I tested the prototype with five participants and used their feedback to improve navigation, filtering and interaction feedback.

I also worked on the Flutter front end, troubleshot development environment setup issues and tested the application using an Android emulator.

## Tools Used
- Figma
- Flutter / Dart
- Android Emulator

## Project Scope
This is an academic front-end project. Checkout is simulated; there is no live payment processing or production backend.
